How your income affects your payments

The payments gradually start decreasing when the AFNI is over ${{ income_threshold_1 | round: 0 }}. The reduction depends on your AFNI and on the number of children you have.

Income below ${{ income_threshold_1 | round: 0 }}

You receive the maximum amount for each child. No reduction is applied.

Income between ${{ income_threshold_1 | round: 0 }} and ${{ income_threshold_2 | round: 0 }}

Your total payment is reduced based on the number of qualifying children:

{% for tier in reduction_table %} {% endfor %}
Reduction rates for AFNI between ${{ income_threshold_1 | round: 0 }} and ${{ income_threshold_2 | round: 0 }}
Number of children Reduction rate
{{ tier.num_children }} {% if tier.num_children == "4+" %}or more{% endif %} {{ tier.rate_mid | times: 100 }}%

Your reduction is calculated as: rate × (your AFNI − ${{ income_threshold_1 | round: 0 }})

Income above ${{ income_threshold_2 | round: 0 }}

Your total payment is reduced further. The reduction has two parts: a base amount plus a percentage of income above ${{ income_threshold_2 | round: 0 }}.

{% for tier in reduction_table %} {% endfor %}
Reduction rates for AFNI above ${{ income_threshold_2 | round: 0 }}
Number of children Base reduction Additional rate
{{ tier.num_children }} {% if tier.num_children == "4+" %}or more{% endif %} ${{ tier.base_reduction }} {{ tier.rate_high | times: 100 }}%

Your reduction is calculated as: base reduction + rate × (your AFNI − ${{ income_threshold_2 | round: 0 }})
